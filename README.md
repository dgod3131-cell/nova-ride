# NOVA RIDE

NOVA RIDE is an original mobile-first realistic motorcycle open-world game created by XenoDimensionals.

## Core MVP

- Account authentication
- Persistent player profile
- Level system
- RM economy
- Motorcycle ownership
- Motorcycle upgrades
- Third-person motorcycle gameplay
- 360-degree free camera
- Mobile controls
- Speed / RPM / gear HUD
- Garage
- Settings

## Backend

Supabase handles:

- Authentication
- Player profiles
- Player settings
- Owned motorcycles
- Motorcycle upgrades
- Persistent game data

## Design

UI and visual direction are maintained in the NOVA RIDE Figma and Canva project.
